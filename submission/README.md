The demo uses actual application captures, an explicitly labelled illustrative
polypropylene scenario and real public catalog records. It uses synthetic
narration and the private local Gemini connection. The public site uses Firebase
AI Logic; the participant confirmed public profiling works in Chrome/Edge on
17 October 2026. The voice token service separately passed a real Gemini Live
audio/tool smoke test on the same date. No completed waste transaction, verified
buyer acceptance or realized savings are claimed.

Firebase is the deployed hosting path. **Cloud Run is not used in this release.**
See the main repository README for setup, source provenance, processing terms,
free-quota limits and the difference between prototype features and production
roadmap work. The entry must be submitted through the participant portal; these
files do not constitute a portal submission.
